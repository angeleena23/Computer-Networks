# Assignment

*Module 1 Assignment – Computer Networks (PCCST501)*

# Title

*How the Internet Delivers a Web Page*

*Website Chosen:* Amazon (https://www.amazon.com)

# Objective

To understand how a web page is delivered over the Internet by studying the TCP/IP protocol stack, DNS name resolution, HTTP communication, TCP reliability, Client–Server architecture, cookies, and the interaction of application-layer protocols during web browsing.

# Solution

This assignment explains the complete process of loading the Amazon homepage after a user enters its URL in a web browser. It covers the TCP/IP protocol stack and the role of each layer, DNS domain name resolution, HTTP request and response process, TCP's reliable communication mechanisms, Client–Server architecture, comparison of HTTP and FTP, the use of cookies for improving user experience, and the complete communication flow between the browser and the web server with supporting diagrams.

# Output

A comprehensive report demonstrating how the Internet delivers a web page using the TCP/IP model and application-layer protocols. The report includes protocol explanations, comparison tables, communication flow diagrams, and a real-world example using the Amazon website.

# Conclusion

This assignment provided a clear understanding of how different networking protocols work together to deliver a web page efficiently and reliably. It demonstrated the importance of DNS, HTTP, TCP, cookies, and the Client–Server model in modern web communication, helping to understand the complete journey of data from the user's browser to the web server and back.
